AlwaysNightVision

A simple Paper plugin that gives all players permanent Night Vision.

Features

* Automatically gives Night Vision to all players
* Re-applies Night Vision when joining the server
* Re-applies Night Vision after respawning
* Re-applies Night Vision when changing worlds
* No particles
* No commands required
* No external dependencies

Compatibility

* Paper 1.26.2

Installation

1. Download AlwaysNightVision-1.0.0.jar
2. Put the JAR file into your server’s plugins folder
3. Restart the server

That’s it! All players will automatically receive Night Vision.
